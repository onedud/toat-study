# Tody — 민트 파스텔 공부기록

공인중개사 · 오픽 · 9급 공무원처럼 자격증마다 따로 기록하는 학습 웹앱입니다.
공부 시간(토디테이블), Tody time 스톱워치, 토디펫 십이지신 도감, 할일, 오답노트,
마스터노트, 인증 사진·일기, 타이머 통계, 그리고 취업 준비용 Job mode(채용달력·할일·토디팁·스크랩북)를
한 화면에서 관리합니다.

- 앱: https://onedud.github.io/toat-study/
- HTML 파일 하나로 동작하며, 설치 없이 브라우저에서 바로 열립니다.
- 기록은 사용하는 기기(브라우저) 안에 저장됩니다. 통계 ⚙️에서 JSON 백업을 받아 두세요.

## 주요 기능
- **토디펫**: 공부한 만큼 자라는 펠트 인형 펫. 알 → 유아기 → 성체, 무지개 7색, 십이지신 12종 도감.
- **Tody time**: 과목 아이콘을 누르고 시작하는 미니멀 스톱워치. 실행 중엔 민트, 멈추면 회색.
  완료하면 토디테이블 칸과 펫 성장 게이지에 자동으로 기록됩니다.
  - **☀️ 화면 켜짐 유지**: Tody time이 달리는 동안 화면이 꺼지지 않습니다(지원 브라우저만, 일시정지·종료 시 해제).
  - **🔊 힐링 ASMR**: 빗소리·바람·물방울 마림바를 브라우저에서 직접 합성해 들려줍니다. 사운드 파일 없이
    동작하고, 버튼 한 번으로 켜고 끌 수 있어요(끈 상태가 기본).
  - **🍅 뽀모도로**: 자유 / 25분 / 50분 중 고르면 시계 아래에 목표 진행률이 보이고, 목표에 닿으면
    시계 둘레가 민트빛으로 반짝입니다. 그 순간 키우는 토디펫이 말풍선으로 응원해 줍니다
    ("25분 완주! 잠깐 물 한 잔 어때요? 💧"). 반짝여도 공부 시간은 계속 흘러가요.
  - **화면 배치**: Tody time은 폰을 돌리지 않아도 됩니다. 세로로 들면 세로 그대로, 폰을 눕히면
    그 화면에 맞춰 자연스러운 가로 배치로 바뀝니다(강제 회전 없음).
- **토디테이블**: 주간 스트립 · 총 공부 시간 · 과목별 타이머(과목 아이콘) · 24시간(0시~23시) 칸 타임라인.
- **할일**: 일간/주간/월간 달력, 주간 날짜별 체크리스트, 카테고리 추가, 완료 보기.
- **오답노트 / 마스터노트**: 3일 · 7일 · 한달 복습, 사진 첨부, 과목 필터.
- **인증 사진 · 일기**: 날짜 칸을 눌러 사진과 줄긋기 일기를 남기면 달력에 썸네일로 표시됩니다.
  홈 `tody calendar`는 **이번 달만** 테두리 없이 보여 주고(사진은 날짜 숫자 없이 정사각 썸네일, 오늘은 민트 칸),
  헤더의 `기록일/이번 달 전체 ›`를 누르면 **월간 기록 아카이브**가 열립니다 — 기록이 있는 달만 넘겨 보며
  달성률 진행 바와 함께 지난 사진·일기를 다시 볼 수 있어요.
- **오늘의 명언**: 홈펫 말풍선에 명언 100선 중 한 줄이 보입니다. 다른 탭·모드에서 홈으로 돌아올 때마다
  새 문장으로 바뀌고, 말풍선을 눌러도 문장은 그대로입니다.
- **타이머 통계**: 일간/주간/월간 총 공부 시간, 과목별 비중, 추이 그래프.
- **Job mode**: 상단 토글로 취업 준비 모드로 전환. 채용달력(전형·결과 상태), 취업 할일, 토디팁(기업분석·면접복기),
  **📁 스크랩북**(기사 제목·원문 링크·태그·내 의견을 모아 두고 검색·수정·삭제)이 들어 있습니다.
- **🏆 스펙 진열장**: Job mode에서 상단 `오뇨님`을 누르면 Study 타이머 통계 대신 내 자격증·트로피가
  투명 유리 선반에 시간순으로 진열됩니다. 자격증은 금빛 봉황 테두리 증명서(Certification · 자격증명 ·
  발급기관 · TODY 도장), 트로피는 금색/은색 컵으로 보이고, 누르면 **토킹포인트**(자소서·면접에 쓸 어필 포인트)와
  함께 상세 팝업이 열립니다. `+ 추가`로 등록·수정·삭제하고, `📷` 버튼으로 선반 전체를 고해상도 PNG로
  저장하거나 공유할 수 있어요(버튼은 이미지에 들어가지 않습니다). 자격증 테두리·도장 이미지는
  `cert-border.png` · `tody-seal.png`.

# Tody — 민트 파스텔 공부기록

공인중개사 · 오픽 · 9급 공무원처럼 자격증마다 따로 기록하는 학습 웹앱입니다.
공부 시간(타임테이블), Boost mode 스톱워치, 토디펫 십이지신 도감, 할일, 오답노트,
마스터노트, 인증 사진·일기, 저장한 명언, 타이머 통계를 한 화면에서 관리합니다.

- 앱: https://onedud.github.io/toat-study/
- HTML 파일 하나로 동작하며, 설치 없이 브라우저에서 바로 열립니다.
- 기록은 사용하는 기기(브라우저) 안에 저장됩니다. 마이페이지/통계 ⚙️에서 JSON 백업을 받아 두세요.

## 주요 기능
- **토디펫**: 공부한 만큼 자라는 펠트 인형 펫. 알 → 유아기 → 성체, 무지개 7색, 십이지신 12종 도감.
- **Boost mode**: 과목을 고르고 시작하는 미니멀 스톱워치. 실행 중엔 민트, 멈추면 회색.
  완료하면 타임테이블 칸과 펫 성장 게이지에 자동으로 기록됩니다.
- **타임테이블**: 주간 스트립 · 총 공부 시간 · 과목별 빠른 타이머 · 24시간 그리드(드래그 채우기).
- **할일**: 주간 날짜별 체크리스트, 카테고리 추가, 완료 보기.
- **오답노트 / 마스터노트**: 3일 · 7일 · 한달 복습, 사진 첨부, 과목 필터.
- **인증 사진 · 일기**: 날짜 칸을 눌러 사진과 줄긋기 일기를 남기면 달력에 썸네일로 표시됩니다.
- **저장한 명언**: 홈 펫의 말풍선에 오늘의 명언이 보이고, 펫을 누르면 명언 카드 모음이 열립니다.
- **타이머 통계**: 일간/주간/월간 총 공부 시간, 과목별 비중, 추이 그래프.
